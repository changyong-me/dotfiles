# Dotfiles

설치 스크립트 없이 에이전트가 적용하는 선언형 설정 저장소. 내 [Desktop](DESKTOP.md)과 [MacBook](MACBOOK.md)을 기기별 문서로 관리한다. 초기 상태의 기기에 Claude 앱을 설치하고 Code 탭에서 아래의 프롬프트를 실행한다.

```md
<https://github.com/changyong-me/dotfiles>를 `~/dotfiles`에 클론한다. `claude/CLAUDE.md`를 읽고 지침으로 사용한다. 기기에 따라 `DESKTOP.md`나 `MACBOOK.md`를 읽고 설정을 적용한다.
```
