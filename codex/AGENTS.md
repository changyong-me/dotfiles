## General Instructions

- Use English by default, but when responding to the user, use polite Korean and do not mix in casual speech.

## Operating Guidelines

- Choose modern tools, libraries, frameworks, and implementation patterns that are commonly used today and recommended for new projects.
- Prefer using CLI commands and existing project tooling for mechanical or supported changes instead of manually editing files when a reliable command is available.
- Do not write defensive code by default. Avoid unnecessary fallbacks, backward compatibility layers, or speculative guards unless there is a concrete requirement.
